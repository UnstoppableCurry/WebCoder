安装指南（按文档原文结构）

文档声明最低配置为 2 核 / 4GB / 20GB 磁盘，系统 Ubuntu 20.04+、macOS 12+ 或 Windows WSL2；推荐 4 核 / 8GB / 50GB 与稳定外网。这些是文档数字，仓库内没有配套基准测试。

系统要求与环境准备

文档要求 Python 3.10+ 与 Node.js 16+（示例使用 Node 18 源），并安装 AI CLI：

npm install -g @anthropic-ai/claude-code
pip install kimi-cli
npm install -g @openai/codex   # 文档标记为可选

Dockerfile 在构建时安装了 Claude Code 与 kimi-cli，未出现 Codex 的 npm 安装行。

方式一：直接安装

git clone https://github.com/yourusername/webcoder.git
cd webcoder
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python -c "from src.db.database import init_db; init_db()"
./scripts/start.sh

当前仓库没有 .env.example。有 requirements.txt 与 scripts/start.sh。start.sh 会在缺少 venv 时创建它，并后台启动 Core 与 Gateway。

方式二：Docker

git clone https://github.com/yourusername/webcoder.git
cd webcoder
cp .env.example .env
docker-compose up -d

仓库含 docker-compose.yml：服务名 webcoder，构建 docker/Dockerfile，映射 3000/3001，健康检查请求 http://localhost:3001/health。可选 profile with-nginx 引用 ./docker/nginx.conf，该文件目前不在仓库中。

方式三：开发模式

文档要求 requirements-dev.txt、pre-commit install 与 ./scripts/start-dev.sh。这些文件当前均未出现在仓库中。

文档中的环境变量示例

DEFAULT_AI_PROVIDER=kimi
KIMI_API_KEY=your-kimi-api-key-here
KIMI_API_URL=https://api.moonshot.cn/v1
CLAUDE_API_KEY=your-claude-api-key-here
CLAUDE_API_URL=https://api.anthropic.com
JWT_SECRET_KEY=your-super-secret-jwt-key
EMAIL_ENABLED=false
EMAIL_SMTP_SERVER=smtp.gmail.com
EMAIL_SMTP_PORT=587
EMAIL_SENDER=your-email@gmail.com
EMAIL_PASSWORD=your-app-password

密钥获取步骤文档指向 Moonshot 开放平台 与 Anthropic Console。src/config.py 另外读取 CODEX_API_KEY / CODEX_API_URL。

文档中的验证命令

curl http://localhost:3001/health
curl http://localhost:3000/api/health
claude --version
kimi --version

Core 源码中存在 /health。Gateway 源码中未找到 /api/health。

文档 FAQ（原文要点）

  • command not found: kimi：把 pip bin 加入 PATH，或 pip install --user kimi-cli。
  • Permission denied：chmod +x scripts/*.sh，mkdir -p ~/.webcoder。
  • 端口占用：lsof -i:3000 / 3001，或导出 GATEWAY_PORT / CORE_PORT。
