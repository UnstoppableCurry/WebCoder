快速入门（文档所述，非在线演示）

快速开始文档要求先确认 Python 3.10+ 与 Node.js 16+，安装 Kimi CLI（文中写「推荐」）与 Claude Code，并导出 KIMI_API_KEY。

启动平台（文档命令）

git clone https://github.com/yourusername/webcoder.git
cd webcoder
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
./scripts/start.sh

然后「打开浏览器访问 http://localhost:3000」。默认账号在 quickstart 与 scripts/start.sh 中均为：

  • 用户名：admin
  • 密码：admin123

start.sh 还打印「请登录后立即修改密码！」。该口令与 ensure_default_admin() 一致，属于仓库写明的初始值，不是外部用户数据。

创建项目与常用操作（仅文档文字）

  1. 点击右下角 + 按钮
  2. 输入项目名称
  3. 选择 AI 提供商（文档写 Kimi / Claude / Codex）
  4. 点击「创建并启动」

终端中可以直接输入自然语言，或使用如 ls -la、python main.py 的命令。会话操作文档列出：新对话、继续、重启。文件：点击工具栏文件图标以浏览、编辑、上传/下载。

这些步骤描述的是 Gateway 生成的 UI 行为；本站无法演示点击结果。

文档 FAQ

提示 "API Key 未设置"
在 .env 中设置对应密钥。
无法连接到终端
检查 Core：curl http://localhost:3001/health。
如何切换 AI 提供商？
创建项目时选择，或修改环境变量 DEFAULT_AI_PROVIDER。

源码里 Core 使用的名字是 AI_PROVIDER，配置文件导出的是 DEFAULT_AI_PROVIDER，二者是否已接通见 局限页。
