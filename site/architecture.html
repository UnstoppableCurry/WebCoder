源码结构

Gateway 对外，Core 管 PTY

启动脚本会先后拉起 python src/core.py 与 python src/gateway.py。配置默认 CORE_PORT=3001、GATEWAY_PORT=3000。

运行时拓扑（按源码阅读）

浏览器 · 请求 Gateway 返回的 HTML（/, /app, /admin）· 静态 xterm · WebSocket /ws/{project}
↓ HTTP / WS（JWT 查询参数）
Gateway · FastAPI title「Claude Mobile Gateway v10」· 业务 API、webhook、Supervisor
↓ httpx / websockets 到 CORE_URL · webhook 回到 GATEWAY /webhook
Core · FastAPI title「Claude Code Core v10」· fork + pty · exec CLI · /health · /providers
↓ os.execvpe(command)
PROVIDER_CONFIGS 中的命令：claude / kimi / codex（外加管家路径上的 DeepSeek HTTP API）

Core 的 create_process 在子进程中 chdir 到项目目录，把提供商环境变量写入 env，再执行配置里的命令。对 Kimi，若目录会话不存在，continue 模式会回退为 new。默认 skip_permissions=True 时会附加各提供商配置中的 skip 参数（例如 Claude 的 --dangerously-skip-permissions）。

存储、用户与默认管理员

Gateway 启动时调用 init_db()，按 src/db/migrations/*.sql 顺序执行。可见表包括管理员、用户、验证码、refresh token、项目、代理状态、输出历史、管家消息/事件/计划、Git 配置等。

ensure_default_admin() 在不存在用户名为 admin 的管理员时，创建口令 admin123。启动脚本同样打印该组合，并提示登录后立即修改。

项目文件默认根目录来自环境变量 PROJECTS_BASE_DIR（代码默认 /var/lib/webcoder/projects）；数据目录 DATA_DIR 默认 ~/.webcoder。

认证模块使用 PyJWT 与 argon2。Access token 默认 15 分钟，Refresh 默认 7 天。

代理系统

  • Supervisor：单例，启动时恢复「运行中」项目的 ProjectAgent，并跑任务循环与健康检查循环。
  • ProjectAgent：注释描述约 10 秒心跳读取 Core 输出，调用 DeepSeek 判断环节，并可向进程写入指令。
  • ButlerAgent：根据输出生成推进提示词；Gateway 另有 /api/butler/chat 走 deepseek_service.butler_chat。

Git 相关注释写明：版本管理已集成到 ProjectAgent 心跳，不再使用独立 git_worker。

Gateway 挂载的 API 前缀

前缀模块源码中出现的能力

/api/projectsprojects.py / files.py / butler.py项目启停、代理动作、文件与 Git、管家处理

Core 另提供 GET /health、GET /providers 以及按项目名的 start/stop/restart/input/status/output 与 WebSocket。安装文档还写了 GET /api/health；当前 gateway.py 中未检索到该路由，见局限页。

README 目录树与实际布局

README 画出 src/core/、src/gateway/ 等子包。当前仓库对应的是单文件 src/core.py、src/gateway.py，另有 src/agents/、src/api/、src/auth/、src/db/、src/services/、src/config.py。静态终端资源在仓库根目录 static/，Gateway 则尝试挂载相对自身的 src/static（若该路径不存在则跳过）。

依赖见 requirements.txt：FastAPI、uvicorn、websockets、httpx、aiosqlite、PyJWT、argon2-cffi、aiosmtplib、pydantic、python-dotenv 等。
